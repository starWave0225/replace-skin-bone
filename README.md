# 画皮：借面

国风志怪、俯视角移动的浏览器剧情 RPG。基于《画皮：借面》GDD v1.0，结合后续确认的「可行走地图」与《聊斋志异·画皮》原文方向。

## 运行

需要 Node.js 22.12+。

```powershell
npm install
npm run dev
```

打开 http://127.0.0.1:4173/ 。

```powershell
npm test
npm run build
npm run preview
```

## 在线试玩与部署

GitHub Pages：[画皮：借面](https://starwave0225.github.io/replace-skin-bone/)。

推送到 `main` 后，GitHub Actions 自动安装依赖、运行测试、构建并发布 `dist`。也可在仓库 Actions 中手动运行 `Deploy GitHub Pages`。部署流程从 Pages 配置读取项目目录，图片、配乐与三维素材会使用同一目录前缀；本地 `npm run dev` 仍从根目录启动。

本地构建 GitHub Pages 版本：

```sh
VITE_BASE_PATH=/replace-skin-bone/ npm run build
```

主剧情新稿保存在 `docs/MAIN_STORY-v1.md`；当前发布的可玩剧情仍截止第一章。

## 怎么玩

- WASD / 方向键行走，Shift 疾行，E 与附近的人物、物件或门交互。
- 点击地面自动寻路。右上角「寻路」会让角色实际走向所选目标；手机可用方向按键与「叩」按钮。
- 步行、疾行与自动寻路速度提高约三成。换面后，地图人物的脸、发式、衣着与随身物同步变化，并播放短暂的纸纹易容效果；关闭动态效果后直接切换形貌。
- 新游戏从抄书人陆知微抵达槐阴开始。在栖雨客舍查验半笺、入宿簿和窗下湿泥，作出初步判断，夜宿后进入第一人称三维梦境。
- 梦中点击「步入梦中」后，移动鼠标即可环顾，WASD 行走、Shift 疾行、E 查验、J 案记、G 随灯引路。Esc 暂停 / 释放鼠标，Tab 释放鼠标操作界面；点击画面恢复。鼠标捕获受限时自动采用移入画面即环顾的兼容模式；手机仍用触屏拖动与方向按钮。
- 依次探灯、采笔、画卷、铜镜与门，结合《画皮》原文认识借相。梦醒后从客舍门口前往无面茶楼，才会正式借沈砚之面、进入第一章。
- 梦境采用昏暗夜景与局部灯火；白衣女魂会在帘边、书案、镜中与门侧显影，留下与命案相关的片语。查验后收入右上角「案记」，梦醒客舍仍可展读；进入茶楼后保留在因果录。她的身份、冤情与证词真伪尚未揭晓。
- 有剧情时点击「继续」或按空格。自由探索不消耗行动，完成调查或休息推进时段。
- 第三日黄昏往南街找韩七；其后穿过戚家小院去后井。井边取画后，返回前院与婆婆交谈。
- 行囊可展读拾得的《画皮》原文。面谱中可切换已获得的身份。
- 自动存档与三个手动槽位保存在当前浏览器 IndexedDB 中，包括位置与对话状态。
- 首页「战斗试玩」直接进入独立回合制斗法：点击面技或按 1–4 出招，Q 守息，F 换面。沈砚擅辨相与破相，周平擅格挡与截招；先打尽皮相，再把握后续两次显形行动压制真形。可选择起手面、重置或败后重试。

## 此版包含

- 七幅俯视角地图：栖雨客舍、无面茶楼、槐阴南街、戚家小院、县衙值房、后井，以及章末王宅残梦；另有独立的 WebGL 三维梦境。
- 新序章：本来身份、故友命案、三物查验、初步判断、夜宿入梦、五物揭相、天明寻人。序章中不开放借面、面谱或第一章养成界面。
- 三维梦境：木构长廊、窗棂、旧画、铜镜反射、悬相、雨尘、动态光影与泛光；支持精细 / 轻量画质和场景配乐控制。采用 Poly Haven CC0 中式宫灯、雕花条案、圈椅、屏风、旧柜模型，以及真实旧木 / 灰泥 / 织物 PBR 材质与夜景 HDRI；全部文件本地打包。
- 房屋/院墙/河水碰撞、石桥、镜头跟随、点击寻路、深度遮挡、人物行走、室内外切换、触屏控制。
- 第一章开场至章末流程，六个调查事件，三种井边处理与三种章末状态。
- 本心/业债/面契、羁绊与识破状态、因果录、物品、记忆线索、对话记录、存读档。
- 十二段经来源核对的《画皮》古文摘句，分别用于剧情题辞、旧案残影与探索收集。
- 独立战斗试玩：沈砚 / 周平两面、一名缠面影，敌意预告、墨息、破相窗口、识破与反击势、换面冷却、胜败与重试、逐招斗法录。
- 战斗画面采用轻松的像素对战风格：我方背身站在近处圆台，缠面影在远处，配套月下中式小院、双侧资源框和底部四招菜单。换面更换战斗背影，破相时纸面掉落，露出青色鬼灵；出招、受击、攒墨都有短动效和飘字。招式小抄与斗法录可展开查看。
- 本地字体、公开授权古画、Kenney CC0 地形局部、原创青瓦建筑与长衫人物、程序化环境声及七首 PeriTune 授权场景配乐。
- 俯视角地图引入七套 Poly Haven CC0 实拍表面材质：青灰旧瓦、苔石路、腐叶湿土、斑驳灰墙、砖石院墙、旧木地板和深色木纹。材质经 Canvas 统一色调，与原创中式建筑造型结合；运行文件约 658 KiB，全部本地加载。

此版为短篇可玩原型，尚非 GDD 目标中的 45–60 分钟精制第一章。已接入十张专属对话立绘；表情差分与正式音乐尚未完成；独立战斗尚未接入剧情，不含第二章。命案是贯穿后续章节的引线，本次序章不会直接揭凶。

战斗独立试玩：http://127.0.0.1:4173/?view=combat 。首页入口与「梦境试玩」并列，开局即可体验两面战术。此入口不访问正式存档，也不替小满决定井边归宿；强借、禁术、道具与剧情战斗结算仍属后续设计。

主场景独立行图：http://127.0.0.1:4173/?view=world 。可查看七处主地图、步行与点击寻路、通过门口切换场景，并选择昼夜与三种人物形貌。该页用于直接查看美术与行走，人物剧情对白请进入正式游戏；不读写剧情存档。同一套公开材质也已接入正式剧情中的 `WorldView`。

三维梦境独立试玩：http://127.0.0.1:4173/?view=dream 。该入口不读写正式游戏存档，可以直接体验新段落。完整序章请在首页选择「赴槐阴」；旧存档仍可续玩原有章节，新序章不强行插入旧进度。

立绘独立预览：http://localhost:4173/?view=portraits 。当前使用 v2「明清绣像、白描淡彩」立绘，按身份区分衣冠、器物、体型与年龄，保留自然的面貌差异。游戏内随说话人自动显示；主角的立绘随借用面皮变化。同一段交谈中的叙述保留场景人物；独立旁白与原典题辞不显示人物。街头寒暄和时段不合时的回应也使用对话框与立绘。原始 PNG 保存于 `assets-source/portraits/`，运行时 WebP 在 `public/assets/portraits/`，完整生成提示词见 `docs/portraits/prompts.json`，美术方向见 `docs/portraits/art-direction-v2.md`。v1 原稿与生成记录保留。原文中的陈氏救活王生；槐阴县、沈砚、戚婆婆及王宅后续为衍生设定。

## 内容与代码

- `src/game/story.ts`：数据化剧情与选项。
- `src/game/prologue.ts`：主角本来身份、命案线索、序章和梦境的推进规则。
- `src/game/dream-scene.ts`、`dream-navigation.ts`：Three.js 第一人称场景与碰撞寻路。
- `src/components/PrologueView.vue`、`DreamExploration.vue`：序章界面、梦境输入与原文拾遗。
- `src/game/engine.ts`：条件、效果、日程与关系状态。
- `src/game/world.ts`：地图、碰撞、交互点与寻路。
- `src/game/world-renderer.ts`：俯视角地图、建筑、人物绘制。
- `src/game/player-sprite.ts`：主角各借面的四向像素形象与易容过渡。
- `src/components/WorldView.vue`：行走、镜头、输入与场景交互。
- `src/game/classics.ts`：《画皮》原文摘句与出处。
- `src/game/saves.ts`：带版本检查的 IndexedDB 存档。
- `docs/GDD-v1.0.md`：用户提供的设计原稿，原样保存。
- `src/game/combat.ts`、`combat-data.ts`、`src/components/CombatPreview.vue`：独立战斗逻辑、招式与试玩界面。
- `docs/COMBAT_DESIGN-v0.1.md`：回合制战斗设计；文末标注独立试玩实现范围，剧情接入仍待开发。
- `docs/PROLOGUE-v2.md`：新的序章顺序、梦境演出与试玩说明。
- `docs/MAIN_STORY-v1.md`：主剧情初稿，采用多篇《聊斋》的恐怖方向，包含六章脉络、命案真相、人物动机、分支承接和四类全篇结局；后续章节尚未接入游戏。
- `ASSET_CREDITS.md`：公开素材与许可。

自动化检查覆盖剧情跳转、分支条件、重复结算、时段取舍、九类终局组合、300 条确定性随机路线，以及地图出生点、门口落点、可达性与碰撞。


### 场景配乐

首页、序章、主地图、梦境与战斗右上角均有「♫ 开启配乐」。首次点击后再点「播放配乐」开始；可调音量、展开七首场景曲目试听，点击「跟随场景」恢复自动切曲。配乐按需读取本地 OGG，并提供 M4A 兼容版本；不依赖第三方在线播放。浏览器页面隐藏时暂停，切回时尝试恢复，若浏览器阻止则点击播放重试。音量偏好与剧情存档分开保存。

日常采用 Chinese / Healing 曲目，茶楼用 Shenxian 无鼓版，后井与县衙采用 Suspense，梦境采用 Suspense3；斗法使用 Wuxia2 的古筝与琵琶版，胜利后转 Taohua。未改动战斗数值与剧情推进。授权及文件校验记录见 `ASSET_CREDITS.md` 和 `docs/music-public-assets.json`。
