# 画皮：千面

国风志怪、俯视角移动的浏览器剧情 RPG，结合《聊斋志异·画皮》的异闻与古文。

当前已接通重构版序章与第一章试玩。剧情文字初稿与交互设计见 [序章 v3](docs/PROLOGUE-v3.md)。新游戏依次经过客舍查案、街头喊冤、茶楼暗室、第一人称雪宅梦境与枯井回声斗法，拾取青布后播放片尾并显示《画皮：千面》。片尾可继续进入第一章「借皮入世」。七日之约当前作为剧情设定，片尾采用已有图像的动态蒙太奇。

后续方案见 [六章剧情、三身份解谜与成长设计](docs/STORY-SIX-CHAPTERS-v1.md)：序章加六章正文，三个可借身份为沈砚、周平、柳照雪，陆知微本相另计；含十八个正文主线谜题、章末战斗、人物成长与四种结局。第一章已按新版剧情接入，第二至第六章尚未开放。

序章已增加两段可暂停、跳过的图像 CG：开匣偷袭后进入梦境；循回声推门后，鬼童 CG 接入教学战。独立预览为 `?view=cg&scene=ambush` 与 `?view=cg&scene=well`。CG 播放期间隐藏常驻底栏，支持手机横竖屏与减少动态效果。新画面、鬼童战斗立绘与生成提示词记录于 [CG 素材说明](docs/story-cg-assets.json)。

片头旧谱使用毛笔手写字。末页通过点击或轻触书旁的蜡烛显字：火苗偏斜熄灭、烛芯留下一点余烬，烟丝升起，暖光随之退去，残谶从纸上浮现。吹气音效跟随声音开关；暂停和切到后台会停住动画与显字进度。当前版本已移除亮度滑条和设备感光输入，手机横竖屏都可直接点烛火。

梦境试玩（`?view=dream`）与序章梦境采用同一套沉浸探索：WASD 行走、鼠标环顾，手机用方向按钮与划动。走近并触碰女鬼的影子后自动播放简短对白，依次经过喜堂、雪庭、纸灯、采笔、画卷和铜镜。女鬼说完后仍可自由探索，玩家须面向铜镜走至镜前、穿过镜面才能梦醒。探索时隐藏任务面板、进度、案记与常驻底栏，无需查验或记下；操作提示只在入梦时短暂出现。Esc / 右上角暂停图标打开菜单，配乐、画质、辅助引路与退出均收在其中；暂停也会停住对白。设备无法绘制三维场景时可改为轻触影子继续，最后点触铜镜离开。

## 第一章试玩

首页点“第一章试玩”，或打开 `http://127.0.0.1:4173/?view=chapter-one`。独立试玩自动保存在浏览器的专用键中，不写入正式剧情存档；正式游玩在序章片尾点“进入第一章”，沿用自动与手动存档。

可玩路线：无面娘认青布 → 本相拜访戚婆婆并取得托付书 → 茶楼首次借沈砚之面 → 饭桌认亲与座位试探 → 画舍收集、转动并拼合三片残画 → 青布辨名 → 按戏单点画灯 → 带真实纸灯到客舍后井 → 与小满交谈 → 切回陆知微辨认夹层文书 → 背画纸傀战 → 把值夜录交给韩七。

沈砚能认画痕与胶矾，陆知微能辨文书异笔；街坊对两张面孔的反应也不同。铜镜前切换身份，地图形象同步改变。本心、画师共鸣、婆婆信任随剧情选择变化；错答可继续，纸傀战失败可重试，探索不扣时间。第一章只解锁沈砚，第二张借面留到第二章。

地图支持 WASD / 方向键、触屏方向按钮与点地移动；“寻路”可自动靠近调查物。底栏保留地图、行囊、面谱、人物、因果录与存档，光圈可随时关闭。拼图用点选交换和转动按钮，手机无需拖拽。

## 重构前版本的操作与实现记录

游戏场景和主要操作固定在当前窗口内。较长的对话、案情和功能面板用「上一页／下一页」阅读。

- WASD / 方向键行走，Shift 疾行，E 与附近的人物、物件或门交互。
- 点击地面自动寻路。「寻路」让角色走向所选目标。手机可按住方向键、点「疾行」切换速度，靠近后点交互按钮。
- 步行、疾行与自动寻路速度提高约三成。换面后，地图人物的脸、发式、衣着与随身物同步变化，并播放短暂的纸纹易容效果；关闭动态效果后直接切换形貌。
- 新游戏先播放雨夜片头：檐雨、抵店、廊下跟拍、三叩与等待、推门、垂手、见尸、越肩看东厢全景、窗开雷响；到旧谱后等待玩家点击、空格或右箭头逐页翻阅。前四页为相关片语，末页在暗处浮现一首诗；支持时随设备环境光显字，也可手动调暗页内灯火，读清后点击书页继续。环境光不是系统屏幕亮度，普通网页无法读取屏幕背光。阅读没有时限。没有旁白或字幕；Esc 暂停 / 继续，右下角可静音、跳过或返回标题页。演出结束直接进入栖雨客舍，查验半笺、入宿簿和窗下湿泥，作出初步判断，夜宿后进入第一人称三维梦境。
- 梦中点击「步入梦中」后，移动鼠标即可环顾，WASD 行走、Shift 疾行、E 查验、J 案记、G 随灯引路。Esc 暂停 / 释放鼠标，Tab 释放鼠标操作界面；点击画面恢复。鼠标捕获受限时自动采用移入画面即环顾的兼容模式；手机仍用触屏拖动与方向按钮。
- 依次探灯、采笔、画卷、铜镜与门，结合《画皮》原文认识借相。梦醒后先循光圈进入客舍后院，在井边按 E 触发冤魂教学战。完成五回合练习、拾起青布后，返回东厢前往无面茶楼，才会正式借沈砚之面、进入第一章。
- 梦境采用昏暗夜景与局部灯火；白衣女魂会在帘边、书案、镜中与门侧显影，留下与命案相关的片语。查验后收入右上角「案记」，梦醒客舍仍可展读；进入茶楼后保留在因果录。她的身份、冤情与证词真伪尚未揭晓。
- 有剧情时点击「继续」或按空格。自由探索不消耗行动，完成调查或休息推进时段。
- 第三日黄昏往南街找韩七；其后穿过戚家小院去后井。井边取画后，返回前院与婆婆交谈。
- 行囊可展读拾得的《画皮》原文。面谱中可切换已获得的身份。
- 自动存档与三个手动槽位保存在当前浏览器 IndexedDB 中，包括位置与对话状态。
- 首页「战斗试玩」直接进入独立回合制斗法：点击面技或按 1–4 出招，Q 守息，F 换面。沈砚擅辨相与破相，周平擅格挡与截招；先打尽皮相，再把握后续两次显形行动压制真形。可选择起手面、重置或败后重试。

## 此版包含

- 八幅俯视角地图：栖雨客舍、客舍后井、无面茶楼、未闻县南街、戚家小院、县衙值房、戚家后井，以及章末王宅残梦；另有独立的 WebGL 三维梦境。
- 新序章：无旁白图片开场、故友命案、三物查验、初步判断、夜宿入梦、五物揭相、井边初战、天明寻人。片头预加载十张原创图片，使用分镜运镜、门窗分层、可点击的弯曲书页，以及随环境光或手动调光的暗处显诗。声音仅有雨水、脚步、敲门、风雷、翻页与落水，没有背景乐曲，窗开后风声增强，每次翻页触发一次纸声，暂停演出也暂停环境声。演出中离开会停在开场阶段，完成后自动存入调查阶段，继续游戏不会重播已完成的演出。序章中不开放借面、面谱或第一章养成界面。
- 三维梦境：木构长廊、窗棂、旧画、铜镜反射、悬相、雨尘、动态光影与泛光；支持精细 / 轻量画质和场景配乐控制。采用 Poly Haven CC0 中式宫灯、雕花条案、圈椅、屏风、旧柜模型，以及真实旧木 / 灰泥 / 织物 PBR 材质与夜景 HDRI；全部文件本地打包。
- 房屋/院墙/河水碰撞、石桥、镜头跟随、点击寻路、深度遮挡、人物行走、室内外切换、触屏控制。
- 第一章开场至章末流程，六个调查事件，三种井边处理与三种章末状态。
- 本心/业债/面契、羁绊与识破状态、因果录、物品、记忆线索、对话记录、存读档。
- 十二段经来源核对的《画皮》古文摘句，分别用于剧情题辞、旧案残影与探索收集。
- 独立战斗试玩：沈砚 / 周平两面、一名缠面影，敌意预告、墨息、破相窗口、识破与反击势、换面冷却、胜败与重试、逐招斗法录。
- 斗法人物和雨后小院采用封面的木刻淡彩风格。沈砚与周平有各自的背身战斗姿态，缠面影以三张描墨纸面护相，破相后显出井中怨灵。招式小抄与斗法录可展开查看。
- 八处探索地图使用 Pixel-Boy / AAA 的 Ninja Adventure 公开地形图块（CC0）。十种地图人物由本作重绘为正常身形的四向人物，陆知微、沈砚和周平有交替步幅。角色原稿及提示词见 `docs/character-ink-assets.json`，公开图块与旧版角色归档见 `docs/world-pixel-assets.json`。
- 本地字体、公开授权古画、程序化环境声及七首 PeriTune 授权场景配乐。

此版为短篇可玩原型，尚非 GDD 目标中的 45–60 分钟精制第一章。已接入十张专属对话立绘；表情差分与正式音乐尚未完成；序章已接入井边冤魂教学战，独立战斗仍可自由试用两面，不含第二章。命案是贯穿后续章节的引线，本次序章不会直接揭凶。

### 场景配乐

配乐默认开启，进入首页、序章、主地图、梦境或战斗时自动尝试播放。浏览器拦截首次有声播放时，点击页面或按键即可开始，无需另开配乐面板。右上角「♫ 配乐」可暂停、调节音量和试听曲目；静音与音量偏好保存在当前浏览器，刷新后仍保留。配乐按需读取本地 OGG，并提供 M4A 兼容版本。页面隐藏时暂停，返回后恢复；点击「跟随场景」可恢复自动切曲。

开场演出使用独立的纯环境声场景，不播放任何乐曲。雨声与风声直接由 Web Audio 播放，叩门、窗响、雷声和翻页与镜头同步；演出完成后恢复调查场景的配乐。演出暂停、静音、切到后台或离开时，环境声一并停止。

日常采用 Chinese / Healing 曲目，茶楼用 Shenxian 无鼓版，后井与县衙采用 Suspense，梦境采用 Suspense3；斗法使用 Wuxia2 的古筝与琵琶版，胜利后转 Taohua。未改动战斗数值与剧情推进。授权及文件校验记录见 `ASSET_CREDITS.md` 和 `docs/music-public-assets.json`。


### 常驻功能图标

进入可操作场景后，地图、行囊、面谱、人物、因果录、休息与存档以图标常驻画面底部。CG 演出（含片头翻阅旧谱）期间隐藏整条底栏。未解锁入口显示灰色图标与锁记，点按可查看解锁条件。进入客舍调查后开放存档和基础菜单，首次借面后开放面谱，休息仅在自由寻访时可用。序章菜单只显示已知人物、已查验物证和已发现梦中片语。打开面板时暂停片头、地图行走或梦境探索，关闭后恢复原来的暂停状态。

序章保留调查光圈与名称：尚未查验的半笺、入宿簿、湿泥和茶摊老板会显示光圈；物证查验后移除对应光圈，梦醒后改为提示通往西街的出口。


### 2D 地图光圈引导

所有 2D 地图均接入交互光圈：金色双圈标出当前主线或当前可做的调查，较淡光圈标记普通交互点与出口。前往其他场景时，金圈会逐段指向实际可通行的门口；进入目的地后改为指向人物或物件。地图面板中选中调查后，也会跟踪对应路线。调查完成、时段不符或身份不符的事项不再高亮为待办；没有当前可做事项时引向休息点。序章继续使用逐条物证光圈，不提前显示后续任务。

引导规则在 `src/game/world-guidance.ts`，不修改剧情状态或玩家位置。`tests/fixtures/world-guidance.html` 可切换剧情阶段与场景，检查实际地图上的路线及光圈，不读写存档。


### 序章井畔教学战

梦醒后先去客舍后井，靠近金色光圈按 E（或选择寻路中的「井边冤魂」）触发。五步依次为点墨、辨相、勾线、守息、落笔见真，使用与独立斗法相同的真实回合结算，逐步解释敌意、墨息、皮相与形、破相打断、后续两次显形行动，以及守息回墨减伤。金框标出本步招式，其他招式暂时置灰。陆知微以本来面目应战，使的是梦中习得的笔法。

正式流程每回合自动保存，也可使用底栏存档；战斗、遭遇对白和战后线索都可读档续接。战后拾得青布和「戌初」纸屑，收入行囊与因果录；冤魂身份仍待核实。回到东厢后，光圈改引向西街出口。旧版已结束序章的存档继续有效，旧版停在梦醒阶段的存档可进入新教学。
