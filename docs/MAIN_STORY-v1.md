# 画皮借面主剧情初稿

本稿采用悬疑查案与持续压迫的恐怖方向，写清从许文卿遇害到王宅旧案了结的完整主线。故事沿用当前游戏的陆知微、客舍调查、五物梦境及第一章人物关系，后续采用六章结构。

当前可玩内容截止第一章。第二至第六章、命案真相和新人物均为本稿新增设计；原始 `GDD-v1.0.md` 保留，后续编剧以陆知微具有真实身世、王宅镜前女子已经死亡为前提。

## 一 故事核心

陆知微应故友之邀，到未闻县校订一部旧谱，却发现故友已经遇害。为辨认死者最后见过的人，他借上了一张亡者的脸。从此，他在街上遇到等他归家的母亲，在井里遇到等他兑现承诺的孩子，也逐渐发现：县里有些活人正用着死者的身份，有些亡者则被迫替活人承担罪责。

许文卿发现了其中一处错名。有人为了让这个错误继续存在，杀了他。

故事最终需要回答三件事：谁杀了许文卿，三年前王宅里发生过什么，以及陆知微愿意用自己的姓名承担哪些已经知道的事。

恐怖随调查逐渐靠近住处。起初，异常只在梦里；随后，井中的声音跟到街上，借来的记忆出现在日常动作里，最后有人在门外用沈砚的声音，说出玩家刚在旧画中听见的那句承诺。玩家可以逐条找到这些现象的来路，但在查清之前，必须带着疑心继续使用面皮。

## 二 借面与亡魂的规则

1. **陆知微是活人。** 他有入城前的人生、故交和自己的字迹。后续反转不推翻这段身世。
2. **借面需要亡者遗形。** 旧画、面谱、遗物中的残念可以成为凭依，不能凭空复制仍然活着的人。面皮可以带来容貌、声音、习惯和零散记忆，不能令原主复生，也不改变借用者的旧伤与掌纹。
3. **同一亡者可以留下不止一张仿面。** 仿面来自不同遗存，记忆不全相同；认出一张脸不能证明眼前人的身份。周平的仿面将成为这条规则的关键案例。
4. **借来的记忆有范围。** 它保留原主亲历过的片段、当时的误判和少量感官痕迹。不会知道原主死后的事，也不会自动识破别人。
5. **亡魂受到遗骸、遗物和契据牵制。** 被拘的魂可以在相连的物件附近显现。要让魂远离原处，必须移动凭依、解除契约或作出新的安置；普通水井不是任意传送的通道。
6. **鬼影与梦境需要复核。** 亡魂可能恐惧、遗忘、说谎；画中人可能只会重复当年亲历的一小段。它们可以指路，定案仍需物证与相互独立的证词。
7. **换首是另一门禁术。** 它能以亡者遗存缝续、改造活人的肉身，造成记忆侵扰，但不能让死者的魂成为那个活人，更不能凭此增加寿数。
8. **旧谱记录契约，不掌管寿命。** 改名、换面与贿赂可以误导人间查验和阴司拘押，不能改写一个人实际经历过的生死。毁谱会破坏拘魂凭据，也会毁掉受害者申诉所需的记录。

无面娘收取的记忆是安魂的寄托。玩家失去的是某段暖意的声音、面貌或感受，已经查实的事实仍可保存在案记中。使用强术不能消除证据，也不能自动免除其后果。

## 三 主要人物与隐情

### 陆知微

二十七岁，抄书人，替人写过家书、讼词、婚书和讣告。他擅长认字、辨纸、对照不同版本，却习惯认为自己只负责落笔。

许文卿之死让他第一次不得不追问：纸上那一句话，使谁得了好处，又让谁再也无法开口？借面会扩大他的行动能力，也让他的判断逐渐混入别人的习惯。他的变化通过说过的话、兑现过的承诺和保留下来的证据表现。

### 许文卿

陆知微的故友，受雇校订王宅散出的旧谱。他把一份契约册当作族谱来修，后来发现几名尚在人世的人，竟各自对应着一幅早年亡者的画像；几名确已死亡的人，姓名却被刮掉，重新记到了别处。

他最初准备拿这份发现索要更多修谱银，等见到有人因此受害，才决定把册子带走。他请陆知微来，既需要一个熟悉自己笔迹的人，也希望有人替自己留下副本。主角会在中段发现朋友的迟疑与贪念，但他最后确实选择了揭露此事。

### 沈砚与戚婆婆

沈砚三年前受聘为王宅绘像。为了替养母买药，他曾明知画像将用于借面，仍替人描过两张相。直到发现一名原主的魂被拘在画后，他才试图退出。

他答应带小满回家，最终没有做到。他留下的照顾养母的遗愿是真实的，他曾参与的事也要写进案卷。画中再见时，他不会要求陆知微继续做自己的替身。

戚婆婆有自己辨认儿子的方式。姜片、收画的习惯和照料人的动作，早已使她起疑。她是否接受陆知微，取决于相处和坦白之后的日子。她家的灯可以成为安全处，也可能因为玩家把被追索的面皮带回家而受到威胁。

### 韩七与周平

韩七三年前奉命封锁王宅。封门令以防疫为名，他后来听见了求救，却始终没有开门。次日清场时，他见过沈砚和周平的尸身，也参与隐瞒死者名单。

他私留了周平的值夜抄录，把沈砚的部分画稿交给无面娘保存，却一直没有向戚婆婆说实话。今日交出遗物并不能抵消当年的责任。后期他的关键行动是以本人身份作证，承认自己听到了什么、又没有做什么。

周平是真正进入王宅查验过的捕快。他的仿面有两份来路：韩七保存的面谱，以及殷照从旧宅遗物中另制的一张。两张面貌相同，纸料与残留记忆不同。

### 柳见秋

序章中的白衣女魂，本稿定名柳见秋。她生前为王宅誊写契据，三年前封门夜死去，遗骸和姓名被分开收存。殷照利用契据拘役她，使她替自己传递物件、取回流出的旧页。

许文卿遇害当夜，她奉命从后窗接走青布包裹的旧谱。她听见争执，见过来人的周平之面，却没有阻止取谱。起初她以为交还册子便能换回自己的遗骸。

她知道殷照控制着自己，最初却不敢直指其名，害怕他毁骨。梦中的提醒是她一次有限的反抗，也是在试探陆知微能否把她从拘役中带走。第二章必须让她亲口承认自己当夜的行为；她的受害经历与应承担的责任分别处理。

### 无面娘

懂得描相与寄魂，曾将一部分技艺传给殷照。她以为替人保存亡者容貌可以缓解哀痛，后来发现自己的手艺被用来拘魂和冒名，却只选择断绝往来。

她知道王宅旧事的一部分，不知道许文卿被杀的全部经过。她没有及时告诉陆知微师承关系，因为怕自己的旧账随之被翻出来。第四章揭露此事后，玩家可以要求她交出术契、当面作证，也可以继续交换利益。

她与王宅镜前的陈氏是不同的人。她给出帮助时，仍须说明代价与自己不知道的部分。

### 殷照

本稿新增的主线凶手。表面是替祠堂、富户修谱和整治神主的手艺人，也处理王宅遗留的账册。他在第二章开头即以活人身份出现，主动提出替玩家辨认旧纸。

他先替富户伪造过继与继产文书，后来利用借面，让冒名者通过亲属辨认。他再以契据拘住知道实情的亡者，将他们写成自愿服役、欠债未偿的人。收益来自继产、冒名和隐匿罪行，长久作恶则使他越来越害怕自己死后被认出。

许文卿带走旧谱，威胁到了这套生意。殷照亲自杀人取谱，又试图把记录恢复成没有疑点的样子。他擅长利用别人希望见到故人的心情，却无法完整模仿那些由长期相处形成的细节。

他的右手拇指曾被裁纸刀伤过，伤处压印会缺一道细线。第二章补写收据时、第三章旧契的指印里和第四章施术账上，均可见这一痕迹。它能把几张不同的脸连到同一名经手者，仍须结合材料来路与其他证据。

### 王生与陈氏的残影

《画皮》原作中陈氏救活王生，故事在复生后收束。以下经历属于游戏衍生：复生数年后王生病故，陈氏向殷照求助，希望再听丈夫说话。殷照宣称可以留魂归家，实际利用王宅收集遗形、试制仿面。

陈氏曾为此提供钱财与场所，也曾对被带入宅中的人视而不见。直到发现归来的丈夫只是在重复她盼望听见的话，她才试图中止仪式。封门夜，她和其他知情者一同死在宅中。

章末镜前女子是陈氏留下的执念残影。她在重复生前最后一段等待，不是活着的幕后操纵者。

## 四 写作者掌握的案件真相

### 三年前的封门夜

殷照以王宅有疫为由，通过当时经手的衙役递出封门文书。韩七负责守外门，周平入内查验后发现了被拘的魂和失踪者遗物，试图将记录带走。

小满来宅中寻找母亲遗留的物件，被殷照留作仪式的见证。他死于宅内，魂附在沈砚答应送给他的那卷自画像上。沈砚发现时已经来不及救人，仍将画卷与依附其上的童影带出。街坊看见青年抱画，身后跟着孩子；他们并不知道那个孩子已经没有脚步声。

沈砚把带有小满魂念的自画像、半枚王宅契印藏进戚家后井，以井水隔开画上追索的墨痕。他在画背留下照顾养母的嘱托，随后折返王宅接应周平，死在殷照手中。

次日，殷照借清理疫宅之名收走遗物。韩七见过尸身，接受了删减后的失踪案卷，把自己所见压了下去。沈砚留在家中的未完归家图与井底自画像是两件不同的物品。

小满的魂因此随画留在戚家后井。他反复索要自己的脸，是因为仪式将他的画像与沈砚的遗形混作一处；他记得承诺，却已经不能稳定辨认两个人。

### 许文卿为何被杀

殷照请许文卿整治散乱的旧谱，本想找回缺页。许文卿却将族谱、契据和画像逐一对照，发现了冒名与拘魂的记录。带走旧谱后，他寄出真正的邀书，请陆知微来校核副本。

陆知微赶到未闻县时已近戌正。许文卿先在栖雨客舍住下，等来的却是戴着周平仿面的殷照。许知道周平早已死亡，仍让他从后窗进屋，因为对方拿出了自己正在追查的另一页契据。

当晚的交谈确有两名活人参与。鬼影、两种声音和亡者容貌，都不能替代对凶手行为的追查。

梦中女魂只亲历取谱、窗外的动静和部分争执。她没有目击勒杀，不应在后续突然提供完整杀人经过。

### 定案所需的证据

命案需要三条相互补充的证据来路：殷照与许文卿之间的修谱委托及交接记录；现场半笺与殷照留下废页的撕口、笔迹和纸料对照；凶器材料、出入路线及各人的时间证词。相同墨料或一张被认出的脸只能增加嫌疑。

王宅旧案则需要封门文书的原件、周平值夜抄录、遗骸查验和韩七承认删卷的证词。阴司中保存的契据可以补明受拘姓名，但不替代阳间的杀人证据。

## 五 主剧情逐章展开

### 序章 雨夜寻凶

陆知微雨夜抵达客舍，敲门无人应答，推门亲见许文卿的尸体。窗开雷响，书页急翻，雨水在空白页上晕出女子面容，随后消散。开场以图片、动作与声音呈现，没有旁白和字幕；演出结束后由玩家亲手查验三物。官差将他当作约见之人留在县内，他暂时无处投宿，只能在客舍另一间房住下。

夜里，隔壁传来抄书翻页的声音。陆知微记起许文卿校书时，总先将纸角压平，再翻下一页。声音停住，门外有人轻轻试了一次门闩。

这段声响来自柳见秋携出的谱页残念，她借此寻找触过半笺的人。此处只呈现声音与动作，不显现凶手，也不让主角当场认定亡友回来。

梦中保留灯、笔、画、镜、门的顺序。白衣女魂随光退让，只有在玩家靠近物件时才显露片语。到铜镜前，主角第一次看见镜中陌生画师的脸；转过身，背后的薄相仍是空的。梦的出口指向无面茶楼。

本章以陆知微白昼亲手推开茶楼门结束：门后桌上的灯，与梦里一样已经烧短了半截。

### 第一章 借皮入世

借沈砚之面、南街认亲和三日调查沿用当前结构。第一张面带来真实帮助，也使一个原本与陆无关的家庭开始等待他归来。

恐怖在熟悉动作中积累：陆会在尚未决定时伸手去取沈砚常用的笔；后井的童影先问他有没有带灯，随后问他为什么不记得自己的名字。调查越深，这些动作越有出处，主角也越难把它们当作偶然。

第三日子夜，小满索要脸与归家的承诺。保留以情动人、安魂寄灯、冒认沈砚三条路线，各自改变后续同行关系。

取画后回到戚家，保留留下、坦白、离开的章节收束。留下路线会接续当夜陪伴和次日白昼的照料、修屋，再由新的命案线索推动出门；其他路线从客舍或街头接续。决定留下的人可从戚家往返调查；玩家也可在后续停止追查，收束到留灯结局，不用强制转场抹掉他对婆婆的承诺。

章末王宅镜前，陈氏残影说出那句等待。镜中没有陆知微的影像，她重复的是三年前的情境。

### 第二章 灯下无主

殷照到客舍询问许文卿遗物，自称仍欠死者一笔修谱银。他的手艺确实精细，能指出半笺用纸的产地；读到残损落款时，却顺手把一个本该轻收的字写得很重。这个动作先成为疑点，尚不能直接定案。

柳见秋在夜里再次出现。她指向城外废寺，说自己的骨头在那里，愿以当夜所知换陆替她取骨。玩家追查后发现废寺中有许多无字骨匣，匣盖内侧却写着各不相同的借债人名。有人在用亡者的骨，替别人的账作押。

深入骨室时，柳必须承认：她原本受命把追查者带到这里。骨匣上的契线可以拘住借面者，使他无法摘面。她在最后一段路前示警，是否得到原谅由玩家决定；玩家可与她合作、强迫她带路，或另查寺产与埋骨记录。

本章的恐怖场面围绕一盏灯展开。灯照着门时，门外人影总戴着当前所借的脸；将灯移开，能看见那人脚下拖着一条接往骨匣的细线。它只能重复该面留下的记忆，回答不了陆知微自己的来处。

玩家解除柳的契束或找到独立记录后，获得殷照控制骨匣的证据，以及一片与客舍旧谱相连的青布。柳可以交出由遗物摹成的仿面，让主角以旧誊工身份查阅王宅账册；拒绝借面时可通过账房见证和其他旧档进入下一章。

离开寺院后，门外第一次传来许文卿的声音。此声属于殷照新制的仿面残响，只能重复遗物中残留的邀约。他已开始利用陆知微对故友的熟悉来试探他。

### 第三章 画中旧宅

青布中残留的契字与井底画卷同出一册。玩家查明这一点后，以画、灯和本人署名进入王宅留下的画境。

画境沿用宅院结构，却按不同见证人的记忆显出不同房间。周平记得外门落锁，沈砚记得小满从井边走来，柳见秋记得陈氏按住她的手，在契纸上留下一枚指印。每段记忆都在亲历者离开或死亡处中断。

探索时，人物会突然回到原先的位置，继续说上一次没说完的话；搬开的椅子在回头时恢复原位。玩家第一次推开封门，门后仍是一幅关着门的画。离开重复的办法是找出该片段没有被记录的边界，再从现实物证补上缺失。

沈砚的亡魂残片在自画像中与陆相见。他辨认自己参与过的两幅相，也承认自己最初收了银子。他不知道三年来宅外发生的事，先由陆讲述与戚婆婆的相处。若玩家冒认儿子，他会询问戚婆婆如今在等谁；若玩家已经坦白，他会请陆将自己做过的事也写下。

本章揭开三年前的主体经过：小满早已死亡，沈砚带出的孩子是童影；沈把画藏好后又返回王宅；陈氏曾资助仪式，后来试图制止，最终死在屋里。她镜前的等待有具体来历，也有被她忽略的受害者。

玩家可带出沈砚留下的原始绘像草稿和一段记忆。强取全部残念会使他重新陷入封门夜；妥善保存草稿、允许残魂散去，则失去随时追问他的机会，但保留可供比对的证据。

本章末，现实里的王宅外门被人重新钉死。门缝下塞来一张刚描好的周平之面，纸背写着：值夜之人，不得擅离。

### 第四章 换首长街

玩家凭绘像草稿查到一名仍然活着的女子程素娘。她身首之间有一道旧缝，面貌与自己年轻时完全不同，家人却一致声称她从未改变。当地人私下传说，她曾请人仿陆判之术换首。

程素娘没有主动求术。她病重时，丈夫付钱请殷照救治，殷照擅自用另一名亡女的遗首施术，将保存遗形的契据交给丈夫。她活了下来，此后常梦到自己没有去过的地方；丈夫则用契据控制她，威胁要将她当成妖物送官。

初次交谈时，她将桌上的镜子面朝下扣住。陆询问旧日住处，她回答得很慢，手却在桌沿轻轻划出另一座院子的布局。门外丈夫一出声，她立刻收手。夜里，亡女的魂隔窗叫她的名字，叫的是素娘的名字，仿佛也在学着分清这两个人。

亡女的魂仍被拘在另一幅画中。程素娘需要保全自己的肉身与生活，亡女也有权取回姓名、决定遗存如何安置。玩家可以查回亡女原籍、通知其家人，以衣冠归葬和保留施术实录求得双方同意，再于阴司解除役契；素娘则需脱离丈夫的威胁，取得本人可以持有的医案与身份见证。未能取得同意时，这项责任继续保留，不能强行伤害其中一人来宣布事情已了。

本章通过医案、亡女原籍和施术账揭开殷照的完整交易。无面娘必须承认师承关系，交出早年契式。对比后发现，当前旧谱多出的强役条款是殷照后来所加。

阳间命案在本章形成完整证据链。殷照保存的废页能与客舍半笺撕口相合，修谱账记着细绦的领取，韩七查明他当夜曾借后街出入。周平仿面的不同纸料证明两张相同时存在，韩七保管的面谱并不是凶手当夜所用之物。

对质时，殷照不再否认。他提出取回全部契据，换取程素娘平安和柳见秋的遗骨。玩家若接受，能先救下一人，却会失去一部分定案材料；拒绝则要立即安排护送、保管副本，承受他以役鬼追索的后果。

殷照销毁的是能够取到的原件，已经分存的副本仍然存在。玩家此前对证据的处理必须在这里产生作用。

### 第五章 夜审无名

部分受害者的姓名已在人间记录中被刮去，尚存的役契又将他们写成自愿。要解除这部分拘役，玩家需要持旧谱、遗物和见证进入地方阴司的契案库，核查原始收契记录。

本章借鉴席方平入冥申冤的结构。地方掌案吏收受殷照供奉，惯于按旧契押魂。他最初肯受理借来的捕快身份，却拒收陆知微署名的状纸：原卷中没有这个经手人。

堂下几名证人戴着一样的脸，依次陈述彼此矛盾的身世。仔细核对可发现，其中一些是真正受害者，另一些只是从面皮上抽出的记忆残响。强迫役鬼念出想听的证词可以快速过关，也会把整桩案子变成下一份假卷。

玩家需要让愿意作证者说清亲历范围，同时用骨匣编号、契纸骑缝和阳间副本指出原卷的删改。柳见秋承认参与取谱；韩七以本人身份说明封门与删卷；无面娘交代契术的来历。缺少某人的证词时，须以此前取得的独立材料补足，并承担部分事实无法恢复的结局差异。

小满的路线在这里分别兑现：已经安宁的童影不被重新召来；寄灯路线需先完成送归或征得他继续同行的意愿；依附路线会使追索者把陆当成沈砚，玩家须面对先前的冒认并重新取得信任。三条路线都不能让孩子成为强制消耗的开门钥匙。

当掌案吏继续拒绝核对，玩家可以带着已核验的副本越级申诉，也可以接受私下改契。前者能带出正式的驳契文书，须经追捕离开；后者可以安稳带走少数人，但其余姓名继续留在役籍中。

章末，陆知微在状尾写下自己的名字。回到阳间时，天尚未亮，王宅中却有人已经替他写好了另一份契约。

### 第六章 天明之前

殷照准备在第七夜将尚存的役契重新钤合，转嫁自己经手的罪责。他要陆知微撤回状纸、认领经手之责，并以已在契案库登记的署押作新见证，让受贿的掌案吏能够将旧案重新封存。他需要陆的原因是陆已经具状追查此案；同样的欺骗也曾被用在其他告状者身上。

这项期限从第二章被发现的祭单开始明确提示，后续通过领料账和对质复核。第一章的三日安排仍独立成立，后续时段保证调查、护送与进入阴司所需的时间。

| 游戏内日期 | 主线安排 |
| --- | --- |
| 初一至初三 | 第一章三日调查，初三子夜井边取画。 |
| 初四 | 第二章接续戚家或客舍，夜探废寺。 |
| 初五 | 第三章核对画境与现实遗物。 |
| 初六 | 第四章查换首案、留存副本并对质。 |
| 初七白昼及前半夜 | 安排护送，第五章入阴司申诉。 |
| 初七后半夜至初八天明 | 第六章返回王宅，处置役契并收束。 |

序章抵达与入梦发生在初一之前，不占第一章行动。进入阴司的路线须在前两章预告所需凭据；第七夜前半即可返回，不临时以阴阳时差增加或缩短时限。

最后一夜，玩家要同时安排证据和人的去处。已经留存的副本交给可靠见证，受威胁的人转移住处，承诺送归的魂完成安置。若戚婆婆愿意帮忙，她可以保管一份陆知微亲笔的案情，却不会因羁绊足够而自动免于危险。

王宅中，殷照依次借用周平、沈砚、许文卿的面孔。他用捕快口吻命令玩家交卷，用沈砚口吻请求再见母亲，用许的口吻催促烧掉旧谱。玩家需依据本人记下的事实和各段记忆的范围辨认诱导，不能仅靠选择最冷酷的回答通关。

殷照的威胁具体落在契约仍能拘役的魂与未分存的证据上。他不能凭一张脸让亡者真正复生。此前完成的护送、解契和副本分存，会逐项削弱他手里的筹码。

保全证据的路线中，陆依据驳契文书逐项找出可撤的役契，使愿意离开的魂脱离追索；没有取得文书时，则只能拆开已经查清来路、得到本人同意解除的契，其余部分继续形成压力。殷照欲以新契挽回拘束，必须亲手落押。他换过几张脸，拇指上的缺线始终留在纸上。玩家在此将委托书、旧契与新押并列，向在场见证者指出同一经手人。

殷照最后借许文卿之面，请陆将自己从后窗放走。门外应当有人接应，但接应者是谁、是否还有能力守住出口，取决于前面的救援与信任。若韩七愿意作证，他先拦下殷照，再将自己的捕快腰牌放到同一份案卷旁，准备接受追查；若无人能够接应，陆须自行守住出口，承担放弃抢救部分契据的后果。

走公开查办路线时，殷照以本名被拘，案件由本县之外的官员复核，不交回原经手者私了。其他结局则由烧谱、撤离或接掌交易明确收束他的去处。斗法若接入，应围绕破坏追索、保护证人和抢救契据展开，避免击败敌人后自动清空全部责任。

## 六 四类全篇结局

| 结局 | 达成所需的主要行动 | 收束与代价 |
| --- | --- | --- |
| 归名 | 保住足够的独立证据，推动公开查验，解除主要役契，并以本人身份认领自己的行为。 | 许文卿命案与王宅案得到查办。韩七、无面娘及仍在世的参与者分别承担责任。陆知微保有姓名与归处，尚未恢复的受害者记录留作后续查访。 |
| 留灯 | 拒绝接掌旧谱，优先救出身边的人，但未保住足够的案件材料或未能完成全部申诉。 | 一部分魂得以归去，亲近的人活下来；殷照带着残契逃走，部分罪行仍无人能证明。陆知微带着明确未偿的承诺离开或留下，夜里仍有人循未解的契来叩门。 |
| 焚谱 | 在没有完成分契、留证的情况下烧毁总谱，切断本次追索。 | 殷照抢救契卷时死于火中，最后的仪式中止，拘束松动，但一些失名者连最后的申诉凭据也被毁去。幸存者各自保留不同讲述，陆知微知道自己救了谁，也知道哪些名字已经查不回。 |
| 执笔 | 接受殷照的交易，接管契据与役使之权，用替名或强迫证词把自己的牵连写到别人名下。 | 眼前的人可以被保全；殷照交出骨匣钥匙，借另一张面离开，陆获得操纵身份的手段。尾声中他为新的求助者取出一张薄相，继续以别人的姓名处理不能公开的事。 |

结局由已发生的行为和最后处置共同决定。本心、业债可以限制主角抵御侵扰或履行承诺的能力，不能单独代替证据、证人的意愿和救援结果。

戚婆婆的态度、小满的去处、柳见秋是否获自由、程素娘是否摆脱契据控制，分别写入结局后日谈；它们不被一个总标题抹平。许文卿不会在好结局中复活。陆知微最终将其真实经历写成一封给故友家人的信，保留他的过错，也写明他最后试图做的事。

## 七 现有分支如何继续

| 现有选择 | 后续必须保留的结果 |
| --- | --- |
| 对小满以情动人 | 童影已得到安宁，后续使用归家图与故居物证，不重新召魂索取帮助。 |
| 将小满寄于灯中 | 灯需要照看，送归是实际任务。完成后童影可以离开，不强留至终章。 |
| 冒认沈砚安抚小满 | 小满会维护他认定的哥哥，也会因陆摘面感到恐惧。后续提供坦白、修复承诺的机会，伤害已发生。 |
| 坦白后被戚婆婆接受 | 她逐渐以陆知微本人的习惯招待他，能帮助辨认沈砚仿面的言行。 |
| 坦白但尚未被接受 | 可以往来、照料和等待；最终接受不能只靠一次数值判定。 |
| 继续以沈砚身份留下 | 接续一段真实相处，再逐步暴露谎言的压力。殷照会利用玩家不敢摘面的处境。 |
| 留画离开 | 第二章从客舍或街头继续，柳见秋循相关谱页寻找主角。婆婆的帮助需要后续重新建立。 |
| 交出记忆学安魂 | 相应感受确已失去。后续可从案记理解自己曾经的行为，不能无代价取回被交出的体验。 |
| 没有调查县衙或遗物 | 后续可以取得正式案卷和遗骸证据，减少可用的私人记忆，但不把第一章未选事件补成全部亲历。 |

## 八 序章演出与夜宿片段

### 客舍开场（已接入）

使用图片镜头与音效连续呈现，不配旁白、对白框或说明字幕。

1. 雨夜，陆知微走近客栈，镜头缓慢推向房门。
2. 手抬起，敲门三次；停顿，无人应答。
3. 门向两侧打开，许文卿的尸体露出；镜头稍近，停在房内。
4. 窗扇突然弹开，雷光照亮房间，风雨吹向书案。
5. 书页急翻，逐渐停在空白页。
6. 雨水落下，湿痕扩散，女子的面容从纸上显现，又随水墨散去。
7. 画面淡出，进入可操作的东厢调查。演出未替玩家检查线索。

### 第一夜的门外（后续演出草稿）

客舍借给他一间靠楼梯的房。掌柜把灯放下时，特意朝窗闩看了一眼。

陆知微没有脱衣。他把自己的邀书和东厢找到的半笺并排压在桌上，一个字一个字地看。

许文卿写最后一捺时，腕子总往上一提。这张半笺却把笔按了回去。

楼梯响了一声。

他抬头，等掌柜再走一步。外面没有动静。

隔了一会儿，门外传来纸页翻过的声音。先是纸角擦过桌面的轻响，然后才翻过去。很慢，像在等墨干。

陆知微望着桌上的两张纸。他想起这些年替许文卿校过的稿，右下角总有一小块被指腹磨薄的地方。

他起身走到门前，没有开门。

“谁？”

纸声停了。

门闩往上轻轻动了一下。托住它的木槽很浅，那根木头只要再升一点，就会脱出来。

陆知微伸手，按住门闩。

木头另一端随即不动了。隔着一扇门，外面也有什么东西，静静抵在那里。

他一直按着。灯芯慢慢结出一团黑花，桌上的影子短了一截。

直到楼下鸡叫，手下那点力气才松开。
