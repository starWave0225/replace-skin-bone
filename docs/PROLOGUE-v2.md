# 序章：雨夜寻凶

本次实现依据后续确认调整开场；`GDD-v1.0.md` 原稿保留。主角有自己的身份，换面是后来接触的技艺。

## 陆知微

二十七岁，以抄书、代写书信为生。受故友许文卿之邀，到未闻县校一部旧谱。抵达时得知故友已在栖雨客舍遇害，因此留在镇上查问。主角不是开场便已知自己为画皮的无名之身。

## 可玩顺序

1. 一封旧约：自己的身份、来意与命案。
2. 东厢调查：可行走客舍；查半笺、入宿簿、窗下湿泥。三物全部核实才可继续；可另问茶摊老板。
3. 初步判断：来者经过后窗 / 许兄认得来人 / 时辰尚未对上。记录判断，不自动判定凶手。
4. 夜宿：收好书信，带着未解之事熄灯。
5. 梦中寻相：切为第一人称三维木廊，依次查验五物。
6. 天明：回到自己的身体与客舍。步行至「西街尽处」，在现实中找到无面茶楼。
7. 茶楼：以陆知微之名问许文卿的旧谱与执笔之人；无面娘说明沈砚之面可能通往王宅的旧线索。此后才正式借面，接回原有第一章。

## 梦中五物

| 顺序 | 物件 | 演出与意义 | 原文摘句依据 |
| --- | --- | --- | --- |
| 一 | 纸灯 | 陌生廊道与隔帘声音；拾灯后出现随身灯光 | 一更許，聞門外戢戢有聲，自不敢窺也。 |
| 二 | 采笔 | 书信笔锋与描相相连；看过后帘幕缓开 | 見一獰鬼……執采筆而繪之。 |
| 三 | 画卷 | 借相如披衣；帘后悬相显现 | 已而擲筆，舉皮如振衣狀，披於身，遂化爲女子。 |
| 四 | 铜镜 | 真正的房间反射与异相；提醒姓名仍属于自己 | 愚哉世人，明明妖也，而以爲美…… |
| 五 | 门 | 无面茶楼匾额显现，门后之人指向西街 | 游戏衍生对白，未标为原文 |

原句取自现有 `classics.ts` 已核对的古文；相关出处见 `ASSET_CREDITS.md`。许文卿、陆知微、未闻县、茶楼和具体梦境为本作衍生，不属于《画皮》原著情节。

## 操作与存档

- 桌面点击「步入梦中」后申请捕获鼠标，移动鼠标即转向，无须按住鼠标键；WASD 行走，Shift 疾行，E 查验，J 案记，G 随灯引路。方向键左右仍可转身。手机保留触屏拖动环顾与方向按钮。
- Esc 暂停 / 释放鼠标，Tab 释放鼠标操作界面；点击画面继续。打开查验或案记时自动释放，点击确认 / 收起时重新申请捕获；最后一物完成后不重新捕获。失焦、隐藏页面、画质重建和离开梦境均释放鼠标并清除移动输入。
- 浏览器拒绝捕获时，兼容模式为鼠标在画面内直接移动即可环顾，仍无须拖动。完整捕获依赖前台页面中的点击；兼容模式受画面边界限制。
- 「随灯引路」采用碰撞路径步行到下一件物件，抵达后转向它；查验仍由玩家确认，不自动跳过。
- 查验卡片中「记下此事」后才推进。Esc 返回操作说明或关闭查验。
- 精细画质使用阴影、铜镜反射与泛光；轻量画质降低像素比和反射分辨率，关闭阴影和后期。配乐默认开启；浏览器拦截时，在首次点击或按键后播放，静音偏好随浏览器保存。
- 正式序章自动保存阶段、已见物件、客舍位置与梦中位置 / 视角。旧版存档不需要重开，不强制插入序章。
- `?view=dream` 是独立试玩入口，不读写正式存档。完整流程用首页「赴未闻县」。

## 美术与范围

新增陆知微透明立绘与梦境画卷；原始 PNG、运行时 WebP、提示词与来源映射保存在 `assets-source/prologue/`、`public/assets/`、`prologue-assets.json`。木构、窗棂、镜框、悬相、雨尘与交互动画由程序构建；宫灯、条案、圈椅、屏风、旧柜采用 Poly Haven 的 CC0 中式模型，主要材质替换为摄影 PBR 颜色 / 法线 / 粗糙度贴图，并接入夜景 HDRI。公开素材来源、作者与文件清单见 `dream-public-assets.json`、根目录 `ASSET_CREDITS.md`。场景可以自由行走，不以一幅全景图模拟三维。

这是可玩的梦境原型。命案仍留待后续章节展开；完整角色动作、配音和战斗不在本次新增内容中。

## 白衣冤魂与待核案记

梦境改为昏暗夜景：减少全屋环境照明与月光，保持首灯、随身灯和书案局部可见。常驻灯火缓慢明灭；门、家具、窗棂仍保留真实材质，不用全黑遮住场景。

新增一名姓名未明的白衣女魂。她表示有冤未申，随探索在帘边、书案后、画轴附近、铜镜与门侧显影；淡出后才换位，模型遮挡仍有效。表现使用透明人物影像、朝向与浮动、薄雾和镜中叠影，尚无完整人物骨骼动作。女魂不是原著陈氏，身份与死因留待后续，不在序章给出凶手答案。

| 五物 | 女魂片语指向 | 现实中待核之处 |
| --- | --- | --- |
| 灯 | 戌初、窗下仍有人 | 鞋印何时留下，与交谈时辰能否对应 |
| 笔 | 半笺末一行收笔过重 | 原邀约与添写字迹应分开细辨 |
| 画 | 送茶人是否看见了脸 | 不能用两个人的声音，替代对两名来客的确认 |
| 镜 | 认得容貌未必认得其人 | 须结合来意、行止与物证，不凭鬼影断案 |
| 门 | 旧谱经过谁的手 | 到无面茶楼寻执笔者，追问旧谱的经手人 |

每次亲自查验并确认后，右上「案记」才收录该条。打开案记暂停行走；未得线索不会提前展示。存档继续使用已见五物的有序记录，兼容现有版本。梦醒后客舍案簿保留五条待核疑点；可再次问茶摊老板，得知小二只隔门听声、未见第二人的脸，许文卿携来过青布包裹的旧谱。进入茶楼后，因果录新增「灯外的冤声」。

原文仍单独标作《聊斋志异·画皮》；女魂对白、案件疑点和上述衍生设定不冒作蒲松龄原文。
