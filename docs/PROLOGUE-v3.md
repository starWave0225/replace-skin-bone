# 《画皮：千面》序章剧情与游戏设计初稿

## 序章 · 雨夜寻凶

### 一　栖雨客舍

陆知微靠抄书代笔谋生。故友许文卿来信，说未闻县有一部旧谱待校，约他雨夜在栖雨客舍东厢相见。陆知微沿廊叩了三声，房里迟迟无人答应。门一推就开了，许文卿倒在榻边，手已经冷了。风从背后灌入，吹开后窗。

案上有许文卿留下的书册。前几叶夹着邀书，记有小二隔门听见的人声、铜镜照相的异闻和一段王家的旧事。王宅曾设喜筵，席散，宾客归家，次晨落雪。闻说此后王家衰败，再未见人。

灯暗后，末页的墨字浮了出来。

> 灯尽方知镜中路  
> 井边三叩闻回声  
> 众里寻他千百度  
> 问罢前程黜旧人

陆知微验看屋里，拾到半封写给自己的信。开头几行是许文卿一贯的疏朗笔迹，写到「戌时，东厢候」时，收笔忽然尖重。宿簿记的是酉时一人投宿，戌初送茶的小二却听见两人在交谈。泥鞋印从铜镜前一路拖到窗下，偏偏镜后是实墙，门前的地砖也干干净净。

陆知微将三处疑点带去问掌柜。掌柜听到泥印是从铜镜起的，便不愿再往镜子那里看。他说许文卿入宿时也问过无面娘，劝陆知微到西街尽头的无面茶楼打听。

### 二　街头有人喊冤

街上，卖灯人拦着行人为儿子作证。他说这阵子另有两家遭了入室凶杀，县衙寻不着凶手，抓了几个与衙门有过节的人顶罪。他儿子被收监那日，手上的灯油还没洗净。这番话记作街谈，往后仍须对证。

玩家可以停步问话，也可以径直去茶楼。

### 三　茶楼暗室

无面茶楼前堂亮着灯。无面娘端走一杯凉茶，只说今夜无客，问案应去县衙。陆知微在前堂看到一张烟熏过的旧曲牌，上面还辨得出一句。

> 旧楹联，红褪墨残谁来揭？

木梯通向二楼转角。墙板下沿有一道细缝，往里一推，露出墙后的暗室。室里有一只木匣，匣盖刻着「旧楹联，□□□□谁来揭？」。填入「红褪墨残」，木匣才开。里面叠着一具眉眼俱全的皮囊。

背后有衣袖擦过墙板。无面娘说了句「看得太早了」。陆知微还没转身，后颈便挨了一击，眼前一黑。

### 四　雪宅借相

陆知微睁眼时，已经站在一处陌生宅院。门上的囍字歪了，喜烛只剩半截。白衣女魂回头看他一眼，穿过厅堂。外头已听不见雨声，中庭却覆着白雪，老树上吊着一具看不清面目的尸身。女魂叫陆知微别去解绳，接着领他往书房走。

书房里有纸灯、砚台和一卷未完成的画。没人执笔，那支笔却自己蘸墨，画出一张陌生面孔。女魂叫陆知微抬头。她的眉眼已经和画中一模一样，开口仍是方才的声音。

> 「人非我所杀。有人借这法子驱鬼杀人。我也有冤。借你此术七日，替我问个清白，再找一找我那年等的人。至于回去的路，你得自己找。」

书房深处还有一面铜镜。镜里映出的房间没有雪，也没有喜烛，只见床边一盏尚温的茶。陆知微伸手，镜面荡开一圈水纹。

### 五　枯井三叩

陆知微醒在无面茶楼二楼。无面娘让他暂住此处。他问起梦里那张脸，她说，借一张脸，也得借那个人的眼睛去看旧事。前些日子有个叫沈砚的画师冤死在狱里，或许能成为他日后的第二张面容。眼下，她让陆知微先回栖雨客舍，看看后堂那口枯井。

陆知微想起残谶，在井口连叩三次。第三声落下后，后堂多出三道门，只有一道门后传回响动。循声推门，门后站着一个攥着青布的鬼童。他低声说「别过来……它又要借我的脸」，身边的假相却扑面而来。陆知微仍是自己的相貌，以梦里所见的笔法辨相、破相，压下了怨势。

雾散后，门槛上剩下一角青布。他认得布上的针脚，和梦中书案上那方布相同。陆知微收起青布，暂留作下一程查案的凭据。

收取青布后，序章收束。片尾依次回闪雨夜东厢和画皮意象，最后显出题名《画皮：千面》。

## 第一章 · 借皮入世

序章只铺到陆知微得知沈砚死于狱中、借面之术为期七日、青布有待查证。第一章将从适应新身份与继续查案展开。后续六章及三个可借身份的完整设计另见 [六章剧情、身份解谜与成长初稿](STORY-SIX-CHAPTERS-v1.md)，目前仍为设计稿。

| 段落 | 玩家操作 | 触发与反馈 |
| --- | --- | --- |
| 雨夜片头 | 翻阅许文卿的书册，末页点触书旁的蜡烛将其吹灭 | 火苗摇晃熄灭、烟丝升起、暖光退去后残谶显字。进入调查后可在井前阶段回看 |
| 客舍勘验 | 调查半笺、宿簿、镜前至窗下的湿鞋印 | 两种字体呈现笔迹差异。集齐三项后与掌柜交谈，开放街巷出口 |
| 街巷 | 进入茶楼前可询问卖灯人 | 喊冤证词收入案情，标明由卖灯人陈述 |
| 茶楼 | 读旧曲牌，上楼摸索墙板，补写匣盖残句 | 答案为「红褪墨残」，错误可重试。开匣触发无面娘击晕陆知微 |
| 雪宅 | 第一人称探索喜堂、雪庭与书房，触碰女魂的影子推进演出，最后穿过铜镜离开 | 自动落笔和女魂易相逐步呈现。七日是剧情期限；对白自动播放，无需查验或记下 |
| 枯井 | 连续叩击三次，从三个方向中循回声推门 | 第三次生成方向并显示三道门。左右用声道区分，三个方向均有字幕。走错可回井边重听 |
| 斗法与片尾 | 以陆知微本相完成五步回合教学，拾取青布 | 青布入行囊，播放可跳过的图像蒙太奇，再显示标题 |

调查光圈可以随时通过设置开关。井门用相同的光圈标记，正解由回声与字幕给出。片头、开匣入梦和片尾期间隐藏底栏。

新增开匣偷袭 CG 约十三秒，使用开匣、身后人影、出手和暗场四镜；鬼童 CG 约十四点六秒，在推开正确的回声之门后播放，使用枯井、门缝、童影和假相四镜。二者为专属插画配合程序运镜、字幕与音效的演出，提供暂停、静音、跳过及手机布局。鬼童 CG 同样隐藏底栏；播放或跳过后才进入教学说明，不会直接跳过教学或发放青布。
