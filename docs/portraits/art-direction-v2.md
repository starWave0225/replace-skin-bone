# 对话立绘 v2：古代市井与志怪绣像

本轮按「更有中国古代的特点，人物不必都长得完美」调整九名对话人物。使用内置 imagegen，以 v1 原稿为编辑参考，重新绘制面貌、衣冠与线条。透明底和对话中的左右站位沿用现有接入。

## 画法与衣冠

- 采用明清绣像、白描淡彩的方向：清楚的墨线、克制的矿物色、衣物上的旧绢设色质感。
- 以 GDD 的康熙年间虚构县城为衣冠方向。瓜皮帽、布巾、发辫、斜襟与对襟布衣、布带和围裙按人物身份区分；这是志怪游戏美术设定，不作为服饰考据复原。
- 画师持笔、捕快携卷宗与腰牌、老妇捧粗陶碗、茶贩持铜壶与茶盏、扎灯匠拿竹骨纸灯、陈氏持铜镜。器物帮助辨认人物身份。
- 不统一修成俊美脸型；保留小眼、宽鼻、耳形差异、疲态、胡茬、斑点和自然不对称。衣服有日常磨损，避免人人都穿破烂戏服。

## 美术方向参考

- [大都会艺术博物馆：王翚等《康熙南巡图》第三卷，1698](https://www.metmuseum.org/art/collection/search/49156)：作为时代及市井群像方向的参考资料。
- [台北故宫：陈洪绶相关馆藏介绍](https://digitalarchive.npm.gov.tw/Collection/Detail/14835?dep=P)：作为传统人物画与版画插图方向的参考资料。
