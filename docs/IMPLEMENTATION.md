# Demo 实现约定

本版同时遵循设计原稿与后续确认：游戏为俯视角可行走 RPG；探索地图已重置为公开 CC0 像素图块、小比例古装角色与旧城灰瓦的表现，剧情中增加《画皮》原文。

2026-10-31 更新：新游戏先进入陆知微调查许文卿命案的序章。换面概念延后到序章末尾的三维梦境，随后在现实的无面茶楼正式借面；参见 `PROLOGUE-v2.md`。下面第一章日程从茶楼开始计算，序章不消耗这些行动。

## 日程

开场借面和南街认亲各占一次行动。自由调查开始于初一子夜，余力 1；初二有 3 次行动；初三白昼可再调查一次，黄昏与子夜进入主线。六个调查事件最多完成五个。步行、换场景、换面、读残卷不推进时段。

放弃调查也有韩七提供死亡与童影的最低线索。童影可用当前沈砚之面交涉；故捕快面在井边可换回，避免分支锁死。

## 行走与对话

每幅地图独立定义房屋/家具/河水碰撞及出入口。相邻场景使用预设安全落点。点击人物、地面或寻路栏，角色实际沿可通行路径移动，不直接传送。场景间切换必须先走近出口。

移动速度统一定义于 `world.ts`：步行 160、疾行 245、寻路 190 地图像素 / 秒；键盘短按 6 像素。移动按不超过 4 像素的小步结算碰撞，大位移不会越过薄墙。行走帧随实际行进距离推进，顶住障碍时不原地跑步。

主角像素形貌由当前借面驱动，使用 Ninja Adventure 的不同服饰轮廓近似选配陆知微、沈砚、周平和无相之身。四个朝向及行走姿态读取作者 PNG 精灵表；行走帧按实际距离推进，短帧表按可用行数限制裁切。成功换面后面谱收起，地图上播放 720 毫秒纸纹换相；关闭动态效果后直接呈现新形貌。脚点、碰撞与存档位置沿用原规则。

主线在「借面后出戏楼」「韩七对白后往后井」「取画后回前院」三个位置归还行走控制。剧情和菜单打开时暂停移动。自动寻路采用小步碰撞，在浏览器节流时也不会穿墙。

## 原典与衍生

原典使用识典古籍所载蒲松龄《画皮》古文，原句单独标注。原典中陈氏救活王生，不含未闻县、沈砚与王宅后续。后者保留为 GDD 的衍生设定，避免将新增故事冒充原作。

## 资源表现

古画用于标题与旧梦视觉意象。探索地图用 Canvas 组合 Pixel-Boy / AAA 的 CC0 原生像素地形、建筑、植被、家具和人物表，最近邻缩放；保留按脚点排序的遮挡、雨线、夜色与局部灯光。18 张本地 PNG 约 239 KiB，来源与哈希在 `world-pixel-assets.json`，原摄影表面材质保留历史归档。十张专属对话立绘沿用人物谱。序章梦境仍为按需加载的 Three.js 场景，采用既有 Poly Haven PBR 贴图与中式模型；片头使用独立绘制素材。
